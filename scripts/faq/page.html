Ask ssql

ssql is Unix pipelines for tabular data: read a CSV, JSON or Parquet file, then filter, join, group and sort it one small command per step, and compile the same pipeline to a fast Go program or SQL when it matters. It is free and open source, on GitHub, and you can try it in your browser, with nothing to install, in the playground.

Ask how to do something with ssql. A local model answers, and every pipeline it gives is run against sample data (the playground's employees, orders, customers, flights, cities, signal, and cast: real film casts for six degrees of Kevin Bacon) before you see it.
