## 2026-03-08 (Sunday)

### Streaming Window Functions: Phase 2 + Phase 3

**Phase 2 — Bounded Frames, LAG/LEAD, MIN/MAX (`sql.go`, ~200 lines):**

Added 9 new streaming aggregate types to `StreamWindow()`:
- `swSlidingSum` — ring buffer, add/subtract on eviction
- `swSlidingAvg` — ring buffer + presence tracking
- `swSlidingCount` — returns `min(pos+1, frameSize)`
- `swSlidingFirst` — ring buffer, returns oldest in frame
- `swRunningMin` / `swRunningMax` — O(1) state for default frame
- `swSlidingMin` / `swSlidingMax` — monotonic deque for bounded frames
- `swLag` — ring buffer of `offset+1` values
- LEAD — delayed emission with lookahead buffer

Key changes:
- `newStreamWindowAgg` now accepts `WindowFrame` parameter, routes to running vs sliding variants
- `canStreamWindow` accepts bounded frames (`Following=0`), rejects `Following>0` with helpful message
- `StreamWindow` refactored into `streamWindowImmediate` (no LEAD) and `streamWindowDelayed` (with buffer)
- LEAD uses pending record buffer, flushing on partition boundaries with nil for tail records

**Tests (`sql_test.go`, ~350 lines):**
- Differential test against `Window()` for bounded frames
- 11 per-function tests: sliding sum/avg/count/first, running min/max, sliding min/max, lag, lead, lead partitioned
- 6 edge case tests: frame > partition, lag/lead > partition, mixed lag+sum, mixed lead+sliding sum
- 2 error tests: Following>0, UNBOUNDED FOLLOWING
- 2 new generation test entries

**Phase 3 — Performance Validation (`window_benchmark_test.go`):**

Benchmarked `StreamWindow()` vs `Window()` on Intel Core Ultra 9 275HX:

| Operation | 10K Window() | 10K StreamWindow() | Speedup |
|-----------|-------------|-------------------|---------|
| Running SUM | 465ms | 6.5ms | **71x** |
| RANK | 858ms | 6.4ms | **134x** |
| Combined (7 funcs) | 208ms | 20ms | **10.5x** |
| Sliding SUM (ROWS 2,0) | 7.9ms | 6.5ms | 1.2x |
| LEAD | 7.6ms | 7.2ms | 1.05x |

Key finding: Running aggregates and RANK show massive speedups (O(N) vs O(N²)), while bounded frame operations show modest gains (~1.2x).

## 2026-03-08 (Sunday)

### Sort: Multi-field Support, String Sorting, Comparator API

Fixed three problems with the `sort` command:
1. **Strings sorted incorrectly** — `extractNumeric()` mapped all strings to 0
2. **Single field only** — no multi-field sorting support
3. **No comparator-based sort** in the library API

**Library changes (`operations.go`, `sql.go`):**
- Added `SortFunc[T any](cmpFn func(T, T) int)` — comparator-based sort filter
- Added `SortRecords(orderBy []OrderField)` — multi-field sort using `CompareRecordFields`

**CLI changes (`cmd/ssql/commands/sort.go`):**
- `FIELD` (single) → `FIELDS` (variadic): `ssql sort dept age`
- Replaced `extractNumeric` + `SortBy` with `SortRecords` for correct cross-type comparison
- Updated code generation to emit `ssql.SortRecords([]ssql.OrderField{...})`
