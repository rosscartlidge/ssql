# Journal — 2026-W26

## 2026-06-22 (Mon) — Exploration doc: interactive help at the cursor

Wrote a design/exploration doc (no code) for showing **help on the
command/flag/arg under the cursor** while editing the line — not just
completion candidates. The user's framing: this is general enough to belong
in **autocli**, with ssql as the first consumer, and the "super cool" angle
is using **tmux** subwindows for the display.

`doc/research/interactive-help-at-cursor.md`, indexed in
`doc/research/README.md`. Pushed to GitHub (commit `9855a91`, docs only).

The grounding insight that shapes the whole proposal: **help-at-point is the
existing completion context rendered as help.** autocli's
`analyzeCompletionContext(args, pos)` already locates the cursor (subcommand
path, current flag, `ArgIndex`, clause) for completion — so help is a *second
renderer* over the same analysis, not new machinery. Verified the help content
already lives in the tree (`FlagSpec.Description`/`ArgNames`/`ArgTypes`, command
`Description`, examples; `GenerateHelp*` render whole commands). There is no
existing `HelpAt`/`-help-at` — it'd be a small new primitive.

Proposed shape:
- **autocli core:** `Command.HelpAt(args, pos) (*HelpResult, error)` mirroring
  `Complete`, plus a `-help-at "<line>" <point>` protocol flag parallel to
  `-complete N`.
- **Triggers:** bash `bind -x` help key reading `READLINE_LINE` (the proven
  Ctrl-O / Ctrl-T pattern); autocli-shell `AutoCompleteCallback(line, pos, key)`
  branch — which sees every keystroke, enabling a live pane.
- **Display (the tmux angle):** inline print (floor) → `tmux display-popup`
  (transient context overlay, fzf-preview-style) → live `tmux split-window`
  help pane that tracks editing → optional in-shell overlay. Gated on `$TMUX`,
  degrades gracefully. Noted a "tutor mode" idea: the pane showing each stage's
  output schema via the existing `generate schema` path.

This is the third member of the `READLINE_LINE` / `(line,pos,key)` action
family — Ctrl-O (complete from upstream schema), Ctrl-T (optimise in place),
and now a help key (explain under the cursor). Confirmed tmux + `display-popup`
are available on this box, so the rich path is buildable.
