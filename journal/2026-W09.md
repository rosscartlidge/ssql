### Window Functions Command

Added SQL-style window functions as a new `window` CLI command and `Window()` library function. Window functions compute rankings, offsets, and aggregates **without collapsing rows** — every input row comes out enriched. This was ssql's biggest analytical gap vs DuckDB.

**Library additions (`sql.go`, ~300 lines):**
- `WindowConfig`, `WindowSpec`, `WindowFrame`, `OrderField` types
- `WindowFunc` sealed interface with 15 concrete types + constructors:
  - Ranking: `WRowNumber()`, `WRank()`, `WDenseRank()`, `WNtile(n)`, `WPercentRank()`
  - Offset: `WLag(field, n)`, `WLead(field, n)`, `WFirst(field)`, `WLast(field)`
  - Aggregate: `WSum(field)`, `WAvg(field)`, `WCount()`, `WMin(field)`, `WMax(field)`
- `CompareAny(a, b)` — cross-type value comparison (nil < numeric < string)
- `CompareRecordFields(a, b, orderBy)` — multi-field record comparison
- `Window([]WindowConfig) Filter[Record, Record]` — main function, supports multiple configs (clauses)

**Algorithm:** Materialize → partition → sort → compute window functions per row → emit with original fields + computed fields. Supports ROWS frame specs (UNBOUNDED PRECEDING/FOLLOWING or fixed offsets).

**Tests (`sql_test.go`, ~250 lines):**
17 tests: row_number, partitioned row_number, rank (with ties), dense_rank, lag, lead, running sum, moving average, count, min/max, multiple configs (clauses), multi-field order, empty input, CompareAny, ntile, percent_rank.

**CLI command (`cmd/ssql/commands/window.go`, ~640 lines):**
- Clause-based design: `+` separator for different window specs
- All 15 window functions as flags with proper arg parsing
- `-partition`, `-order`, `-desc`, `-rows` for window specification
- `-generate` support for code generation
- Schema propagation (adds result fields with inferred types)

**Registration and generation tests:**
- `cmd/ssql/main.go` — registered `RegisterWindow`
- `cmd/ssql/generation_test.go` — 2 generation tests (row-number, partition+sum)

**Example usage:**
```bash
# Row numbering per department
ssql from data.csv | ssql window -row-number rn -partition dept -order salary -desc

# Running total
ssql from sales.csv | ssql window -sum revenue running_total -partition dept -order date

# Top 3 per department
ssql from data.csv | ssql window -row-number rn -partition dept -order salary -desc \
  | ssql where -where rn le 3 | ssql exclude rn

# Month-over-month change
ssql from monthly.csv | ssql window -lag revenue 1 prev_rev -order month

# 3-row moving average
ssql from prices.csv | ssql window -avg price ma3 -order date -rows 2,0

# Different windows via clauses
ssql from data.csv | ssql window \
  -rank salary_rank -partition dept -order salary -desc \
  + \
  -lag date 1 prev_date -order date
```

**Implementation notes:**
- Autocli stores single-arg accumulated flags as `[]any{string}`, not `[]any{map[string]any}` — had to handle both cases in `parseSingleArgSpecs`
- Code generation uses `fmt.Sprintf("%T", fn)` to recover concrete type names from unexported WindowFunc types for emitting constructor calls
- Output order: first config's partition+order order when -order is specified, original input order otherwise
