# Week 13, 2026

## 2026-03-25 (Tuesday)

### Build hash in version output

Added git commit hash to `ssql version` output: `ssql v4.30.0 (build: 1432c632, gpu: no)`. Set at build time via `-ldflags`, falls back to `"dev"` for `go install`. All Makefile targets (build, deb, gpu, playground) pass the hash. Useful for verifying which exact build is running, especially in WebVM where caching is aggressive.

### WebVM: mobile touch bar — reverted

Touch bar for mobile (Tab, arrows, Ctrl keys) caused CheerpX boot failures on Pixel 7. Multiple approaches tried — wrapping `onMount`, overlay vs resize, top vs bottom placement — all broke phone boot while working on laptop. Reverted to pre-touch-bar state. Needs a fundamentally different approach that doesn't touch the Svelte component at all (e.g. pure DOM injection after boot).

### WebVM: SSH support

- Added `openssh-client` and `iputils-ping` to the Docker image (~5.5MB)
- Pre-configured `~/.ssh/config` with Tailscale-friendly defaults:
  - `StrictHostKeyChecking accept-new` — no interactive prompt, but MITM-safe after first connect
  - `ControlMaster auto` / `ControlPath` / `ControlPersist 60` — connection multiplexing for ssql pipelines
  - `ServerAliveInterval 30`, `ConnectTimeout 10`
  - Placeholder host entry for user to fill in
- Auto-generates ed25519 keypair on first boot (guard in `.bashrc`)
- Welcome message now shows `ssql version` with build hash for cache verification
