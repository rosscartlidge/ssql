## 2026-03-25 (Tuesday)

### Build hash in version output

Added git commit hash to `ssql version` output: `ssql v4.30.0 (build: 1432c632, gpu: no)`. Set at build time via `-ldflags`, falls back to `"dev"` for `go install`. All Makefile targets (build, deb, gpu, playground) pass the hash. Useful for verifying which exact build is running, especially in WebVM where caching is aggressive.

### WebVM: mobile touch bar — reverted

Touch bar for mobile (Tab, arrows, Ctrl keys) caused CheerpX boot failures on Pixel 7. Multiple approaches tried — wrapping `onMount`, overlay vs resize, top vs bottom placement — all broke phone boot while working on laptop. Reverted to pre-touch-bar state. Needs a fundamentally different approach that doesn't touch the Svelte component at all (e.g. pure DOM injection after boot).

### WebVM: SSH support

- Added `openssh-client` and `iputils-ping` to the Docker image (~5.5MB)
- Pre-configured `~/.ssh/config` with Tailscale-friendly defaults:
  - `StrictHostKeyChecking accept-new` — no interactive prompt, but MITM-safe after first connect
  - `ControlMaster auto` / `ControlPath` / `ControlPersist 60` — connection multiplexing for ssql pipelines
  - `ServerAliveInterval 30`, `ConnectTimeout 10`
  - Placeholder host entry for user to fill in
- Auto-generates ed25519 keypair on first boot (guard in `.bashrc`)
- Welcome message now shows `ssql version` with build hash for cache verification

## 2026-03-28 (Saturday) — 2026-03-30 (Monday)

### Polishing sprint — real-world usage fixes (v4.32.0)

Used ssql for real work and systematically fixed issues discovered.

### Fail loudly on invalid input

Surveyed all commands for silent failures on typos. Found 10 commands silently producing empty/wrong results for unknown field names or operators.

**Factored shared validation helpers:**
- `Condition` type — replaces anonymous structs in where and update
- `parseConditions()` — parses `-if` flags and validates operators
- `validateFields()` / `validateFieldsSchema()` — checks fields against record or schema

**Commands fixed:** where, update, sort, group-by, join, pivot, window, cast, include, merge. All now error with available field names listed.

Added CLAUDE.md rule: "Fail loudly on invalid input".

### Multi-file `ssql from csv/tsv/json/jsonl`

- `ssql from csv *.csv` reads multiple files sequentially
- Default: require identical schemas (error on mismatch with helpful message)
- `-merge-schemas` flag to opt-in to union of different headers
- `-source FIELD` adds source filename to each record
- Shared `executeFromMultiFile()` with reader function callbacks — no duplication across formats
- Design doc: `doc/research/multi-file-from.md`

### Join field collision detection

Previously, overlapping field names silently overwrote left values with right. Now:
- **Default:** error listing colliding fields with suggestions
- **`-suffix _right`:** suffixes ALL right-side non-key fields
- **`-exclude-left`/`-exclude-right`:** drop non-key fields from one side
- **`-as old new`:** explicit rename (existing)
- Fixed `mergeWithRenames` nil vs empty map semantics
- 8 integration tests for all scenarios

### Per-field sort direction

Sort now uses clauses: `ssql sort dept - salary -desc` (dept asc, salary desc). Duplicate field detection. Fixed SQL generation to handle clause separator in `ORDER BY`.

### Split `to json` / `to jsonl`

- `ssql to json` — pretty-printed JSON array (was `-pretty` flag)
- `ssql to jsonl` — one JSON object per line (was default `to json`)
- Removed `-pretty` flag

### Schema header enforcement

Join and merge now error if right-side file has no `_schema` header, with message suggesting `<(ssql from jsonl FILE)`. Added CLAUDE.md rule.

### Build hash via VCS info

Switched from ldflags to Go's `runtime/debug.ReadBuildInfo()` for local builds (always current, shows `-dirty`). Falls back to embedded `commit.txt` for `go install` from module proxy. Learned: never re-tag a Go module version (checksum database is immutable).

### +flag negation (autocli v4.4.0)

Implemented `+flag` as reverse of `-flag` using autocli's PrefixHandler:
- **Boolean flags:** `+desc` = false, `+all` = false — works for all commands automatically
- **Arg flags:** `+if` and `+if-expr` negate the match — only multi-arg flags with boolean semantics
- **Unsupported +arg flags:** error with clear message
- Fixed autocli: PrefixHandler now propagates to subcommands, single-arg +flags route through map path
- Help text updated for all boolean flags to mention `+` form
- Survey doc: `doc/research/plus-flag-negation.md`

### CLAUSES section in help

All commands now show a CLAUSES section:
- Commands with clauses: descriptive text (e.g. "Conditions within a clause use AND logic")
- Commands without: "This command does not support clauses"
- Added `ClauseDescription` to where and union (were missing)

### Test all generate formats rule

Added CLAUDE.md rule: when changing a command, test `generate go`, `generate sql`, and `generate ssql` — each has its own translation logic.

### Refactor while you work rule

Added CLAUDE.md rule: always look for opportunities to simplify surrounding code when fixing bugs or adding features.
