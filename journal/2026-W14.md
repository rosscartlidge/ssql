# Week 14, 2026

## 2026-03-31 (Tuesday)

### Tab completion for `ssql from <TAB>`

Previously `ssql from <TAB>` only showed format subcommands (csv, json, etc.). Now also shows file/directory completions, so users can type `ssql from da<TAB>` and get `data.csv` alongside `csv`. Required an autocli change: when a subcommand has both nested subcommands and positional flags with completers, return both sets of completions merged.

- **autocli v4.3.7** — `completeWithSubcommands()` now runs positional flag completers alongside subcommand name completion
- ssql updated to use autocli v4.3.7

### SQL generation: rename, cast, update

Added SQL translation for three previously unsupported commands using DuckDB's star expression modifiers:

| Command | SQL |
|---------|-----|
| `rename -as old new` | `SELECT * RENAME (old AS new)` |
| `cast -type field int` | `SELECT * REPLACE (CAST(field AS BIGINT) AS field)` |
| `update -if f op v -set f v` | `SELECT * REPLACE (CASE WHEN cond THEN val ELSE field END AS field)` |

### SQL generation: window functions

Translated all 15 window functions to DuckDB SQL. Supports multi-clause windows (different PARTITION BY/ORDER BY per clause), custom frames (`ROWS BETWEEN ... AND ...`), and `-desc`.

| Category | Functions |
|----------|-----------|
| Ranking | ROW_NUMBER, RANK, DENSE_RANK, PERCENT_RANK |
| Offset | LAG, LEAD, FIRST_VALUE, LAST_VALUE |
| Aggregate | SUM, AVG, COUNT, MIN, MAX |
| Bucketing | NTILE |

Only remaining `generate sql` gaps: `from ssh`/`from catalog` (no SQL equivalent).

### Playground: running total example

Added "Window — running total per product" example showing `ssql window -sum amount running_total -partition product -order order_date` on orders.csv. Now 15 examples total.
