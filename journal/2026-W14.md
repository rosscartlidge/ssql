### Tab completion for `ssql from <TAB>`

Previously `ssql from <TAB>` only showed format subcommands (csv, json, etc.). Now also shows file/directory completions, so users can type `ssql from da<TAB>` and get `data.csv` alongside `csv`. Required an autocli change: when a subcommand has both nested subcommands and positional flags with completers, return both sets of completions merged.

- **autocli v4.3.7** — `completeWithSubcommands()` now runs positional flag completers alongside subcommand name completion
- ssql updated to use autocli v4.3.7

### SQL generation: rename, cast, update

Added SQL translation for three previously unsupported commands using DuckDB's star expression modifiers:

| Command | SQL |
|---------|-----|
| `rename -as old new` | `SELECT * RENAME (old AS new)` |
| `cast -type field int` | `SELECT * REPLACE (CAST(field AS BIGINT) AS field)` |
| `update -if f op v -set f v` | `SELECT * REPLACE (CASE WHEN cond THEN val ELSE field END AS field)` |

### WebVM: docker cp uid/gid fix

Discovered `docker cp -a` doesn't preserve uid/gid (moby/moby#41727). All files in ext2 image end up owned by root, which breaks `.ssh/` (mode 700). Fixed by adding `sudo chown -R 1000:1000 /mnt/home/user/` after copy in deploy workflow. Documented in `claude/playground.md`.

## 2026-04-03 (Thursday)

### Multi-file pushdown (Phase 2 + Phase 3)

**Phase 2: Pushdown syntax.** `ssql from csv *.csv -- where -if age gt 25` spawns a sub-pipeline per file and merges JSONL output. Reuses existing `BuildRemoteCommand` and `SplitOnPlus`. Multi-stage pushdown via `+` separator. Works for csv, tsv, json, jsonl.

**Phase 3: Parallel execution.** Pushdown subprocesses run concurrently, capped at `runtime.NumCPU()`. Output preserves file order by default via per-file channels.

**`-unordered` flag.** Streams records as they arrive through a shared channel — lower memory when pushdown produces large output.

Benchmark (10 × 1M rows, filter):

| Mode | Wall time | Speedup |
|------|-----------|---------|
| Sequential | 6.80s | 1x |
| Parallel ordered | 1.55s | 4.4x |
| Parallel unordered | 1.54s | 4.4x |
