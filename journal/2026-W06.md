## 2026-02-08 (Saturday)

### WAV Audio Format Support

Implemented WAV audio file reading and writing, enabling audio signal processing pipelines.

**New features:**
- Read WAV files with `ssql from audio.wav`
- Write WAV files with `ssql to wav output.wav`
- Stereo channel extraction with `-channel 0|1` flag
- Sample rate propagation via schema header (`sample_rate` field)
- Code generation support for WAV operations

**Supported formats:**
- 8/16/24/32-bit PCM
- IEEE float (32-bit and 64-bit)
- Mono and stereo (stereo mixed to mono by default)
- All samples normalized to [-1.0, 1.0] range

**Example usage:**
```bash
# Read WAV and display samples
ssql from audio.wav | ssql to table

# Extract left channel from stereo
ssql from stereo.wav -channel 0 | ssql to table

# Round-trip with different sample rate
ssql from audio.wav | ssql to wav -rate 22050 output.wav

# Signal processing pipeline
ssql from audio.wav | ssql fft -field amplitude | ssql to table
```
