## 2026-02-06 (Thursday)

### Debian Package Distribution

Created and published pre-built debian packages for easy installation on Linux systems.

**Packages created:**
- `ssql_4.11.0_amd64.deb` (7.4 MB) - Standard CLI, no GPU dependencies
- `ssql-gpu_4.11.0_amd64.deb` (6.9 MB) - GPU-accelerated CLI, requires libcudart

**Package details:**
- Architecture: amd64
- Dependencies: libc6 (standard), libc6 + libcudart (GPU)
- Install location: `/usr/bin/ssql`

**Installation:**
```bash
# Standard version
curl -LO https://github.com/rosscartlidge/ssql/raw/main/ssql_4.11.0_amd64.deb
sudo dpkg -i ssql_4.11.0_amd64.deb

# GPU version
curl -LO https://github.com/rosscartlidge/ssql/raw/main/ssql-gpu_4.11.0_amd64.deb
sudo dpkg -i ssql-gpu_4.11.0_amd64.deb
```
