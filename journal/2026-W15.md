## 2026-04-09 (Wednesday)

### WASI build

Built ssql for WASI (`GOOS=wasip1 GOARCH=wasm`). 14MB slim binary runs on wasmtime with full pipeline support — file I/O, stdin/stdout piping, all commands except SSH/GPU/subprocess.

**Benchmarks (1M rows, filter + group-by + sort):**

| Mode | Time | vs Native |
|------|------|-----------|
| Generated Go (native) | 1.06s | 1.3x faster |
| CLI pipeline (native) | 1.40s | 1x |
| CLI pipeline (WASI JIT) | 5.39s | 3.9x slower |
| CLI pipeline (WASI AOT) | TBD | — |

**AOT compilation** (`wasmtime compile ssql.wasm -o ssql.cwasm`) eliminates JIT startup:
- Small data: 0.018s AOT vs 0.195s JIT — **nearly native** (1.2x)
- Large data: ~5x native (processing-dominated, not startup-dominated)

**Surprising finding:** CLI WASI pipeline (5 × 14MB slim modules) is faster than generated Go WASI (1 × 54MB module) because smaller modules JIT compile faster.

Added to goreleaser (ships `ssql_<version>_wasi.tar.gz`), Makefile (`make wasi`), and README (Option 4).
