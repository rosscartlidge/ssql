### Enhanced Chart Output - Phase 1 Implementation

Implemented enhanced chart features for `to chart` command:

**New Features:**
- Multi-series Y-axis support (`-y field1 -y field2 -y field3`)
- Heatmap chart type using Plotly.js (`-type heatmap -z magnitude`)
- Logarithmic axes (`-log-x`, `-log-y`)
- Color-by-field for scatter plots (`-color region`)
- Color scale selection for heatmaps (`-colorscale viridis`)

**Files modified:**
- `chart.go` - Extended ChartConfig with new fields (ZField, YFields, ColorField, ColorScale); added EnhancedChart(), generateHeatmapHTML(), generateEnhancedHTML() functions; added new HTML templates (heatmapHTMLTemplate using Plotly.js, enhancedChartHTMLTemplate with extended Chart.js features)
- `cmd/ssql/commands/to.go` - Updated registerToChart() with new CLI flags (-y accumulate, -z, -type, -log-x, -log-y, -color, -colorscale); updated generateToChartCode() to use EnhancedChart
- `chart_test.go` - Added tests: TestEnhancedChartMultiSeries, TestEnhancedChartHeatmap, TestEnhancedChartLogarithmicAxes, TestEnhancedChartColorByField, TestHeatmapMissingZField, TestEnhancedChartEmptyData
- `cmd/ssql/generation_test.go` - Updated tests to check for EnhancedChart instead of QuickChart
- `doc/api-reference.md` - Added documentation for EnhancedChart function with examples

**Design decisions:**
- Keep Chart.js for existing chart types, add Plotly.js specifically for heatmaps
- Auto-pivot data for heatmaps (records with x, y, z fields -> 2D grid)
- Use EnhancedChart as the new unified chart entry point for CLI
- QuickChart remains available for simple use cases in Go code

**CLI examples:**
```bash
# Multi-series chart
ssql from sales.csv | ssql to chart -x month -y revenue -y expenses -y profit

# Heatmap from spectrogram
ssql from spectrogram.jsonl | ssql to chart -x time -y frequency -z magnitude -type heatmap

# Logarithmic axes
ssql from spectrum.csv | ssql to chart -x frequency -y magnitude -log-x -log-y

# Color by category
ssql from customers.csv | ssql to chart -x age -y income -color region -type scatter
```

- Chart generation test updated in generation_test.go
- Documentation checks pass

### Specialized Heatmap Command - Phase 3 Implementation

Implemented dedicated `to heatmap` command with optimized spectrogram visualization:

**New Features:**
- Dedicated `to heatmap` subcommand for spectrogram/heatmap visualization
- HeatmapConfig struct with specialized options (ZMin, ZMax, LogFreq, ColorScale)
- Optimized Plotly.js template with interactive controls
- Logarithmic frequency axis support for audio spectrograms
- Custom Z-axis range for dynamic range control
- Code generation support (`-generate` flag)

**Files modified:**
- `chart.go`:
  - Added HeatmapConfig struct
  - Added DefaultHeatmapConfig() function
  - Added HeatmapChart() function

- `cmd/ssql/commands/to.go`:
