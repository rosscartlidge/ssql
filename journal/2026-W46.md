## 2026-11-09 (Mon) — `generate rust` writes JSON and JSONL files

Ross: "add the rust jsonl and json file sinks". This follows the CSV/TSV sinks from yesterday
(W45, f8cc916e). `rustJSONSink` (`cmd/ssql/commands/sink_output.go`) writes through Arrow's
JSON writer:
- `to jsonl`, and no sink at all, use `LineDelimitedWriter`: a null is left out, and no rows
  gives an empty file, as exec writes it.
- `to json` uses `ArrayWriter` with explicit nulls, so every key is in every object, and no rows
  gives `[]\n`, as exec writes it. The difference is that exec indents the array and Arrow does
  not.
- Both write to stdout or to a file. A file that can't be created is named in the error.

The CSV and JSON sinks now share `rustSinkWriter`, which opens stdout or the file, and the batch
loop.

A time now has its `Z`, in JSONL on stdout as well. Before, Arrow wrote
`2024-03-05T01:02:03` with no `Z`, which any reader but ssql takes as local time. The rust lane
is unaffected, because its harness (`equivalence_rust_test.go`) has its own writer. Floats are
spelled `1.0e20` where exec writes `1e+20`; this is added to the float-spelling TODO item.

Found on the way: `rustMain`'s `default:` branch printed JSONL for every sink it didn't know.
That included `to json` and stdout `to markdown`/`to lines`, all exit 0. A parquet with no
file would have done the same, but exec requires the file anyway. `rustRefuseSink` now lists
what the program writes (table; csv, tsv, json and jsonl to stdout or a file; parquet to a
file) and refuses everything else.

Tests:
- `TestGenerateRustWritesTheSinkFile` gains `json`, `jsonl` and `stdout_json` subtests. They
  check that:
  - the rows read back equal exec's file;
  - the JSONL bytes equal exec's, and the JSON parses to the same value as exec's (`sameJSON`),
    on the columns spelled the same;
  - a UTC time carries its `Z`;
  - no rows matches exec byte for byte.

  The byte checks also leave out `s`: DataFusion reads an empty CSV cell as null, exec as "".
  The reader decides that, not the sink.
- `unwritable` covers json too.
- `TestSinkFileIsWrittenOrRefused`: `rust_jsonl` moved from refused to written, and stdout
  `to markdown` and `to xlsx` are refused.

Watched fail: with the time format removed from the JSON builder, the `Z` checks failed in both
kinds. With `to json` sent back to the JSONL default, the array, no-rows and stdout checks
failed.
