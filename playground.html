This playground runs a real ssql binary compiled to WebAssembly — Tab completes commands, flags, operators, files, and pipeline-aware field names (it runs your upstream stages in schema mode, so after a group-by it offers the grouped and aggregate fields); Alt-h (or "? Help") explains whatever the cursor is on. The shell piping is simulated in JavaScript. The real CLI adds more: Unix pipes, process substitution, SSH to remote hosts, and catalog queries across fleets.
Install: go install github.com/rosscartlidge/ssql/v4/cmd/ssql@latest
